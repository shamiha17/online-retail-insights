# 🛒 Online Retail Machine Learning Project

This project performs data preprocessing, feature engineering, and machine learning modeling on an Online Retail dataset to predict product quantity using regression algorithms.

## 📌 Project Overview
The notebook includes:
- Data loading and exploration
- Missing value handling
- Feature engineering from date-time data
- Data encoding and scaling
- Model training and evaluation
- Prediction generation

## ⚙️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost

## 🤖 Machine Learning Models
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- XGBoost Regressor

## 📊 Workflow
1. Data Cleaning & Preprocessing
2. Feature Extraction (Year, Month, Day, Hour)
3. Encoding categorical variables
4. Train-test split
5. Model training & evaluation
6. Prediction export (`sub.csv`)

## 🚀 Goal
To analyze customer retail transaction data and build regression models for predicting purchase quantity.
